# 🦷 Sakthi Dental Clinic Website

A modern, responsive static website developed for **Sakthi Dental Clinic** to showcase dental treatments, clinic facilities, doctor information, and contact details.

## 🌟 Overview

This website provides patients with easy access to information about the clinic, available treatments, FAQs, and contact information. The site is optimized for desktop, tablet, and mobile devices.

## 🚀 Features

- Responsive design for all screen sizes
- Professional dental clinic UI
- Treatment showcase section
- About Us page
- Contact page with clinic information
- Frequently Asked Questions (FAQ)
- Privacy Policy page
- Optimized images and assets
- Lightweight and fast loading

## 💻 Running the Project Locally

### Method 1: Open Directly

Simply open `index.html` in your browser.

### Method 2: Using Python Server

```bash
python -m http.server 8000
```

Then visit:

```
http://localhost:8000
```
